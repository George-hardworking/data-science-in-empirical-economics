## 二、核心研究问题与理论基础
### 2.1 核心经济学研究问题（层级递进，严格符合课程要求）
1. **基准问题**：在中国A股特有的退市风险警示（ST）监管制度下，基于传统线性模型的财务困境预警体系是否存在显著的信息效率损失？非线性机器学习模型能否在样本内与样本外显著提升ST风险的预测精度？
2. **核心问题**：驱动A股上市公司陷入财务困境的核心因果机制是什么？机器学习识别的非线性特征信号，能否区分“相关性特征”与“因果性特征”？
3. **拓展问题**：企业信息不对称程度（产权性质、审计质量、企业规模）是否会显著影响模型的预测效果？基于模型构建的投资策略能否产生显著的经济价值（降低尾部风险、提升超额收益）？

### 2.2 可检验的研究假设
基于信息不对称理论、委托代理理论与企业财务困境理论，提出以下可检验假设：
- H1：非线性机器学习模型（XGBoost/LightGBM）对A股ST风险的样本外预测精度显著优于传统线性模型（Logistic回归、Altman Z-score）
- H2：盈利能力、偿债能力与现金流特征是驱动企业财务困境的核心因果特征，而非传统线性模型中强调的营运能力特征
- H3：信息不对称程度更高的企业（民企、小规模企业、非四大审计企业），机器学习模型的预测边际提升效果更显著
- H4：基于模型预警构建的风险对冲策略，能显著降低投资组合的尾部风险，并产生正的超额收益

### 2.3 文献基础
本项目对标课程Guidelines中的两篇顶刊范文：
1. 对标Netzer et al. (2019)：引入文本挖掘方法提取年报文本特征，验证非结构化数据对预测精度的提升，并量化模型的经济价值
2. 对标Taylor & Druckenmiller (2022)：严格的实证识别策略，结合中国监管制度背景，提供具有政策相关性的量化证据

## 三、数据来源与处理规范（可复现、多源异构）
### 3.1 数据来源与时间窗口
- **时间窗口**：2018-2023年A股上市公司年度数据（6个完整会计年度，覆盖2轮完整的资本市场周期）
- **数据频率**：年度面板数据，预测目标为t+1年是否被实施ST（用t年的财务与非财务数据预测t+1年的ST状态，彻底避免未来函数偏差）
- **数据来源**：全部通过AkShare免费获取，无需Token，国内可直接运行
  1. **核心财务数据**：A股上市公司年度财务报表指标、财务比率
  2. **公司治理数据**：产权性质、审计意见、第一大股东持股比例、董事会规模
  3. **文本数据**：上市公司年度报告“管理层讨论与分析（MD&A）”文本，提取文本情绪与主题特征
  4. **宏观控制数据**：年度GDP增速、行业景气度指数
  5. **标签数据**：上市公司是否被实施ST（*ST/ST）的年度状态数据

### 3.2 核心变量定义
#### 3.2.1 被解释变量（标签）
- `is_ST`：二值变量，若上市公司在t+1年被实施退市风险警示（*ST）或其他特别处理（ST），取值为1，否则为0

#### 3.2.2 核心解释变量（特征集）
| 特征类别 | 具体特征指标 |
|----------|--------------|
| 盈利能力特征 | 每股收益、净资产收益率（ROE）、总资产收益率（ROA）、销售净利率、毛利率 |
| 偿债能力特征 | 流动比率、速动比率、资产负债率、利息保障倍数、现金比率 |
| 营运能力特征 | 总资产周转率、应收账款周转率、存货周转率 |
| 成长能力特征 | 营业收入同比增长率、净利润同比增长率、净资产同比增长率 |
| 现金流特征 | 经营活动现金流净额/总资产、自由现金流/营业收入 |
| 公司治理特征 | 产权性质（国企=1，民企=0）、审计意见（标准无保留=0，非标准=1）、第一大股东持股比例、股权制衡度 |
| 文本特征 | MD&A文本积极情绪得分、消极情绪得分、文本复杂度、TF-IDF核心主题特征（LDA模型） |
| 宏观控制特征 | 行业景气度、年度GDP增速 |

### 3.3 数据清洗与预处理规范（严格可复现）
1. **样本筛选**
   - 剔除金融类上市公司（银行、证券、保险，财务报表结构特殊）
   - 剔除上市不满1年的公司（无完整年度财务数据）
   - 剔除已退市公司（无后续ST状态数据）
2. **缺失值处理**
   - 第一步：剔除缺失值超过50%特征的样本行
   - 第二步：对剩余缺失值，采用行业-年度中位数进行填充（避免全样本中位数的行业偏差）
3. **极端值处理**
   - 对所有连续型特征，进行双侧1%的Winsorize缩尾处理，消除极端值影响
4. **数据标准化**
   - 对所有连续型特征，采用行业-年度标准化处理（减去行业年度均值，除以行业年度标准差），消除行业与时间固定效应的影响
5. **标签对齐**
   - 严格实现t期特征预测t+1期标签，避免未来数据泄露，确保实证设计的严谨性
6. **数据集划分**
   - 采用滚动时间窗口划分：训练集（2018-2020年）、验证集（2021年）、样本外测试集（2022-2023年），避免随机划分带来的未来数据泄露，符合金融时间序列数据的学术规范

## 四、实证分析与模型设计（递进式、可执行、硕士级别）
所有代码需在`scripts/final.ipynb`中按单元格分步实现，每一步均需输出结果验证与经济学解释。

### 模块1：基准模型（传统经济学模型，对标现有文献）
#### 1.1 Altman Z-score 经典模型
- 构建适用于中国A股的Z-score模型，计算每个样本的Z值，设定阈值判断ST风险
- 输出指标：混淆矩阵、AUC、准确率、召回率，作为预测精度的基准线
#### 1.2 Logistic回归基准模型
- 以`is_ST`为被解释变量，所有核心财务特征为解释变量，控制行业与年度固定效应
- 输出指标：回归系数、显著性水平、边际效应、样本内与样本外AUC、混淆矩阵
- 经济学解释：分析线性模型中显著影响ST风险的特征，对应传统财务困境理论

### 模块2：机器学习预测模型（核心预测模块）
#### 2.1 模型选择与训练
- 构建3类机器学习模型，均采用5折交叉验证+网格搜索优化超参数，固定随机种子=42确保可复现
  1. 基准机器学习模型：随机森林（Random Forest）
  2. 核心机器学习模型：XGBoost、LightGBM（梯度提升树模型，擅长捕捉非线性特征与交叉效应）
  3. 稳健性模型：L1正则化Logistic回归（Lasso）
- 训练规范：仅用训练集数据拟合模型，验证集调参，测试集仅用于最终效果评估，杜绝数据泄露

#### 2.2 模型效果对比与统计检验
- 核心对比指标：样本外AUC、精确率、召回率、F1-score、KS值（金融风控核心指标）
- 统计检验：采用DeLong检验，验证机器学习模型的AUC是否显著高于传统Logistic基准模型（解决“提升是否显著”的核心问题）
- 输出：模型效果对比表、ROC曲线对比图、PR曲线对比图（保存至`output/figures/`）

#### 2.3 多数据源增量贡献检验
- 分步检验不同特征集的增量贡献：财务特征→公司治理特征→文本特征→宏观特征
- 输出：每加入一类特征后模型AUC的提升幅度，验证非财务数据、文本数据的信息增量（对标课程范文Netzer et al. 2019）

### 模块3：模型可解释性与特征归因（核心经济学分析模块）
#### 3.1 非线性特征重要性分析
- 基于XGBoost模型输出Gain、Cover、Frequency三类特征重要性，排序识别对ST风险预测贡献最大的Top20特征
- 输出：特征重要性横向条形图（保存至`output/figures/`）

#### 3.2 SHAP值可解释性分析（硕士级别核心内容）
- 计算全样本SHAP值，生成：
  1. SHAP摘要图（beeswarm plot）：展示每个特征对模型输出的正负向影响
  2. SHAP依赖图（dependence plot）：展示核心特征与ST风险的非线性关系
  3. 单个样本SHAP瀑布图：展示高风险样本的特征贡献分解
- 经济学解释：分析特征的非线性影响机制，例如“资产负债率超过多少阈值后，ST风险呈指数级上升”等非线性规律，补充线性模型无法识别的证据

#### 3.3 因果特征归因（双重机器学习DML，硕士级别创新点）
- 采用双重机器学习（Double Machine Learning, DML）方法，分离特征与ST风险之间的相关性与因果性
- 模型设定：以`is_ST`为结果变量，单个核心特征为处理变量，其余所有特征为控制变量，采用DML估计处理变量的平均处理效应（ATE）
- 输出：核心特征的ATE估计值、置信区间与显著性水平，识别真正驱动财务困境的因果特征，解决传统机器学习“只讲相关、不讲因果”的缺陷

### 模块4：异质性分析（拓展经济学深度）
- 按照信息不对称程度对样本进行分组，分别检验模型在不同子样本中的预测效果与特征差异：
  1. 产权性质：国有企业VS民营企业
  2. 企业规模：按总资产分为大规模、中规模、小规模三组
  3. 审计质量：四大审计VS非四大审计、标准无保留意见VS非标准意见
- 输出：子样本模型效果对比表、分组SHAP特征重要性对比图
- 经济学解释：验证信息不对称对模型预测效果的影响，对应信息不对称理论，深化研究的经济学内涵

### 模块5：经济价值检验（对标课程范文，核心加分项）
- 构建模拟投资组合，量化模型的实际经济价值（对标Netzer et al. 2019的ROI提升分析）：
  1. 策略设定：在每年年报披露后，基于模型预测的ST风险概率，剔除风险最高的5%/10%的股票，构建等权重投资组合
  2. 对比基准：沪深300指数、全市场等权重组合、基于Logistic模型构建的组合
  3. 评估指标：年化收益率、夏普比率、最大回撤、下行波动率、尾部风险（VaR）
- 输出：投资组合净值曲线、风险收益指标对比表
- 经济学解释：量化模型为投资者带来的尾部风险降低幅度与超额收益，证明研究的实际应用价值

### 模块6：稳健性检验（确保结论严谨性）
- 完成5项稳健性检验，确保核心结论不受模型设定、样本选择、变量定义的影响：
  1. 替换被解释变量：仅将*ST（退市风险警示）定义为财务困境，剔除普通ST样本
  2. 更换预测窗口：用t-1期数据预测t+1期ST状态，检验模型的提前预测能力
  3. 更换缩尾比例：采用双侧0.5%与2%的缩尾处理，检验极端值处理的影响
  4. 安慰剂检验：随机打乱ST标签，重新拟合模型，检验模型是否存在过度拟合
  5. 更换数据集划分方式：采用逐年滚动窗口训练模型，检验样本外预测的稳定性
